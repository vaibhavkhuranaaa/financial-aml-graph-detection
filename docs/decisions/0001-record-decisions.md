# 0001 Record decisions in this repository

## Decision

Every significant choice is recorded here as a numbered file, written for a reader who was not present.

## Why

A reviewer judges engineering by the alternatives considered, not by the code that survived.

## Alternatives rejected

A single running log: harder to reference from a milestone. Commit messages only: they explain what changed, not what was weighed.

## Not done

No template beyond these five sections, and no tooling to generate them.

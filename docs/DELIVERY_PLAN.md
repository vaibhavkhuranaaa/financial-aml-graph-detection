# Signal Ledger delivery record

## Product boundary

Signal Ledger is an anonymous, read-only deterministic replay workbench for
bounded realistic synthetic banking data. It is a portfolio research
demonstration, not a compliance product, production monitor, accusation, or
statement about real people or organizations.

The public service has no authentication, telemetry, server-side visitor
persistence, request-time inference, live feeds, or write API. Browser-local
simulated notes are never sent to the server.

## Delivered scope

- Typed FastAPI GET contracts for health/readiness, case catalogue/detail,
  timeline, bounded topology, evidence, provenance, and methodology.
- Six deterministic IBM AML-Data v8 cases / 55 transactions, materialized from
  the owner-approved checksum-bound source.
- Accessible React investigation desk with timeline replay, bounded topology,
  provenance, uncertainty, and browser-private simulated review records.
- Local-only chronological Elliptic baseline/message-passing evaluation runner
  and owner-approved aggregate summary.
- GitHub Actions verification, Docker portability checks, and one public-review
  Vercel production deployment.

## Acceptance checks

- Deterministic fixture rebuild matches the committed artifact.
- API/configuration tests pass; malformed inputs receive safe errors and write
  requests/local-only routes are rejected.
- Frontend lint and production build pass.
- Public browser checks show rendered content without errors.
- Deployment readiness reports approved artifact delivery with no inference or
  visitor persistence.
- Graphify is refreshed after committed code changes.
